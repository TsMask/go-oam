# WebSocket Web 客户端测试工具

基于 go-oam/ws 的 WebSocket 客户端 SDK，提供友好的 Web 界面来测试 WebSocket 服务端功能。

## 功能特性

- 🎨 **美观的 Web 界面**：现代化的响应式设计
- 🔌 **完整的 WebSocket 客户端 SDK**：封装在 HTML 页面中
- 📊 **实时性能指标**：QPS、延迟、成功率等
- 🚀 **多种测试模式**：
  - 单条消息发送
  - 批量消息发送
  - 性能压力测试
- 📝 **消息日志**：实时显示发送和接收的消息
- 🔄 **自动重连**：支持连接断开后自动重连
- 💡 **多种消息类型**：支持 echo、ping、info 等消息类型

## 快速开始

### 1. 启动服务器

```bash
cd examples/ws/client-web
go run main.go
```

服务器将启动：
- HTTP 服务器：http://localhost:8082
- WebSocket 服务器：ws://localhost:9092

### 2. 访问 Web 界面

在浏览器中打开：http://localhost:8082/index.html

### 3. 测试功能

1. **连接服务器**：点击"连接"按钮
2. **发送消息**：
   - 设置消息类型（如：echo, ping, info）
   - 输入消息内容（JSON 格式）
   - 点击"发送消息"按钮
3. **批量测试**：
   - 设置发送次数
   - 点击"批量发送"按钮
4. **性能测试**：
   - 点击"性能测试"按钮
   - 系统将自动发送 1000 条消息并统计性能

## 支持的消息类型

服务端支持以下消息类型：

### 1. echo
回显消息，将客户端发送的数据原样返回。

```json
{
  "type": "echo",
  "data": {"message": "Hello"}
}
```

### 2. ping
心跳消息，服务端返回 pong 响应。

```json
{
  "type": "ping",
  "data": {}
}
```

### 3. info
获取服务端信息，包括连接 ID 和当前连接数。

```json
{
  "type": "info",
  "data": {}
}
```

## 性能指标说明

- **QPS**：每秒请求数（Queries Per Second）
- **平均延迟**：请求到响应的平均时间（毫秒）
- **成功率**：成功响应占总请求数的百分比
- **总耗时**：测试完成的总时间（毫秒）

## 界面功能

### 连接管理
- 输入服务器地址
- 点击连接/断开按钮
- 查看连接状态

### 消息交互
- 选择消息类型
- 编辑消息内容（支持 JSON）
- 发送单条或批量消息
- 实时查看消息日志

### 性能测试
- 查看实时性能指标
- 监控 QPS 和延迟变化
- 统计成功率和错误率

## 技术栈

- **前端**：HTML5 + CSS3 + JavaScript ES6+
- **后端**：Go + go-oam/ws
- **协议**：WebSocket + JSON

## 文件结构

```
client-web/
├── main.go      # 服务器主程序
└── index.html   # Web 客户端页面（包含完整 SDK）
```

## 注意事项

1. 确保端口 8082 和 9092 未被占用
2. 如果端口被占用，可通过环境变量修改：
   ```bash
   PORT=8083 go run main.go  # 修改 HTTP 端口
   ```
3. 批量发送时请注意服务器性能
4. 性能测试会自动重置指标
